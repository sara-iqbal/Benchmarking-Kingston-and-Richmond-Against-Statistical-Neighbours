How it was built

01LoadDfE Children in Need and Children Looked After releases, plus the official statistical neighbour lists.
02RecogniseEach data set is identified by its columns, so the pipeline survives file name changes between releases.
03CalculateTwelve indicators for every council, recalculated from counts where possible, with suppressed values left blank.
04CompareEach borough against its neighbours' average, London, England and a national ranking.
